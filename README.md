# 让 GPT 把话讲清楚

给 Codex 和 ChatGPT 的一套中文表达指令。简单问题直接答，复杂问题把原因、条件和关键步骤讲清楚。复制一份文本即可开始，无需安装插件。[看三个回答示例](personal/试读.md)

## 快速开始

**ChatGPT 网页版或桌面版**。打开「设置 → 个性化 → 自定义指令」，在「ChatGPT 自定义指令」中粘贴下面链接里的文本并保存。已有内容时先备份，再合并表达偏好。打开新对话试用。[复制 ChatGPT 指令](personal/ChatGPT.txt) · [官方设置说明](https://help.openai.com/en/articles/8096356-chatgpt-custom-instructions)

**Codex**。把下面链接里的小节合并到全局 `AGENTS.md`。默认在 `~/.codex`，设置了 `CODEX_HOME` 时到该目录查找。有非空的 `AGENTS.override.md` 时改那个文件。已有同名小节就更新该节，其他规则保留。打开新会话试用。[复制 Codex 指令](personal/Communication-Style.md) · [官方加载说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

如果不确定哪个文件生效，在 Codex 里粘贴下面这段话，再把表达规范一起贴给它。

> 请先定位本机实际生效的 Codex 全局指令文件，检查覆盖文件和已有的表达规则。备份后，把我附上的 Communication Style 合并进去，保留其他约定。验证新的 Codex 会话能读到它，并告诉我改了哪个文件、原文件备份在哪里。

## 改成自己的习惯

先用一个熟悉的问题试写，比如「为什么两个班的平均分都提高了，总平均分反而下降？」如果解释跳过了你关心的一步，就在对应指令里补一句具体偏好。每次改一处，再用同一道题试读，比较哪个版本更容易跟上。

- 希望先听懂原理，可以写「我问『为什么』时，先用一个具体例子讲原理。公式影响结论或我问到计算时，再展开推导。」
- 希望工作汇报更便于核查，可以写「先说用户能看到什么变化。给出实际运行的验证和结果，并指出还有哪些结果待确认。」

只想调整这一次回答，可以把偏好直接写在提问里。想撤销长期调整时，恢复先前保存的自定义指令文本，或从全局文件中恢复原来的表达小节。
